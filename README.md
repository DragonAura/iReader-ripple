掌阅 Ocean6 Pro 任意第三方软件水波纹助手，实现监控按键触发水波纹、触屏不触发水波纹。可自行调整水波纹/瀑布动效，也可自行调整速度。

## 安装与授权

1. 安装 APK，打开“实体按键水波纹”。
2. 点击“开启 / 管理无障碍监听”，在系统页面中开启本应用的无障碍服务。
3. 若系统提示“受限设置”，返回应用，点击“授权引导 / 受限设置”，再点“打开应用信息”。如应用信息右上角的“⋮”菜单中有“允许受限设置”，点击并按系统提示确认，然后返回应用重新开启无障碍服务。
4. 点击“选择监听应用”，选中需要使用水波纹的阅读应用并保存。阅读应用本身需要支持实体按键翻页。
5. 在已选应用中使用实体翻页键。可在助手中切换水波纹 / 瀑布动效，以及慢 / 标准 / 快三档速度。

不同设备固件的设置入口和名称可能不同。没有“允许受限设置”菜单不一定表示授权被限制，可先尝试开启无障碍；若仍提示受限且没有此入口，可能是固件隐藏了设置，请联系设备厂商。若跳转到应用列表，请手动找到“实体按键水波纹”。

授权引导只打开原生系统设置页面，不会自动授予或绕过权限。开启服务后无需连接电脑。

## 适用范围

动效依赖掌阅设备固件提供的墨水屏接口，主要面向 Ocean6 Pro。无障碍服务能够开启，并不代表其他设备也支持这些动效。助手仅在所选应用中响应实体翻页键；触屏和自动翻页不触发动效。
